# Diagramas

Esta pasta contém os diagramas desenvolvidos para o projeto de Banco de Dados da Trattos.

## Arquivos

- `DER_Trattos_Conceitual.png` — Diagrama Entidade-Relacionamento (DER) conceitual da Trattos, desenvolvido no BRModelo. Apresenta as principais entidades, atributos, relacionamentos e cardinalidades identificadas durante a modelagem conceitual.

- `Modelo_Logico_Trattos.png` — modelo lógico da Trattos, desenvolvido no BRModelo. Apresenta as tabelas resultantes da conversão do modelo conceitual, incluindo atributos, tipos de dados, chaves primárias, chaves estrangeiras e cardinalidades.

Os diagramas foram utilizados como base para a construção do dicionário de dados e do script SQL da Entrega 2.
